## ✨ Project Features
* **Modern UI Design:** Uses a beautiful linear gradient background (`#1d2671` to `#c33764`).
* **Glassmorphism Effect:** The navbar and hero sections feature a trendy frosted-glass look using `backdrop-filter`.
* **Smooth Animations:** Includes subtle hover effects and scaling animations for a better user experience.
* **Interactive Contact Section:** Features a working "Copy Email" button that utilizes the JavaScript Clipboard API to let visitors copy my email with a single click.

## 🛠️ Technologies Used
* **HTML5:** Semantic structure of the web page.
* **CSS3:** Custom styling, flexbox layouts, Google Fonts (Poppins), and smooth transitions.
* **JavaScript (Vanilla):** Logic for the interactive copy-to-clipboard functionality.
